 # URBAN VOID

  Eine minimalistische Streetwear-Webseite als Uni-Projekt.

  ## Beschreibung

  URBAN VOID ist eine fiktive Streetwear-Marke. Die Webseite präsentiert die Markenphilosophie durch ein interaktives Gedicht-Layout und einen minimalistischen Online-Shop.

  ## Features

  - **Infinite-Scroll Gedicht**: Text scrollt automatisch links und rechts neben einem zentralen Video
  - **Hover-Effekt im Shop**: Produktbilder wechseln bei Hover zwischen Vorder- und Rückseite
  - **Responsive Design**: Optimiert für Desktop, Tablet und Mobile

  ## Technologien

  - HTML5
  - CSS3 (Animationen, Flexbox/Grid, Media Queries)


  ## Seiten

  | Seite | Beschreibung |
  |-------|--------------|
  | `index.html` | Homepage mit Manifesto und Video |
  | `shop.html` | Produktübersicht mit 9 Artikeln |
  | `about.html` | Über die Marke und Philosophie |

  ## Installation

  1. Repository klonen
  2. `index.html` im Browser öffnen

  Kein Build-Prozess nötig – rein statische Webseite.
